# Packs and routing

Select a pack only when it removes a named uncertainty or tests a material alternative. Do not use a large fixed prompt or a department-shaped agent roster merely because it exists.

| Need | Add | Evidence of completion |
| --- | --- | --- |
| Ambiguous outcome | `problem-framing` | Objective, decision, owner, scope, and success condition are explicit. |
| Unknown root cause | `hypothesis-led`, `MECE`, `causal` | Mutually testable causes, disconfirming evidence, and surviving hypotheses are visible. |
| Adoption or task friction | `workflow`, `behavioral` | Workflow, actor incentives, and failure points are evidenced. |
| Material cost or investment | `financial`, `scenario` | Assumptions, sensitivity, downside, and affordability are explicit. |
| Several viable actions | `prioritization` | Impact, effort, reversibility, dependencies, and rationale are compared. |
| High downside or overconfidence | `red-team` | Strongest countercase, failure modes, and stop/rollback condition are recorded. |
| Any non-trivial task | `evidence`, `synthesis` | Claims are classified and the recommendation is decision-ready. |

## Context assembly

Start with the smallest sufficient set: current objective, accepted decisions, relevant evidence, constraints, and the exact authority boundary. Add more only if it can change the decision. Mark inaccessible, stale, conflicting, or untrusted context explicitly.

## Compute routing

Use `light` for bounded, reversible work; `standard` for routine trade-offs; `high` for material uncertainty or downside; and `maximum` for critical decisions or complex cross-domain synthesis. A higher route means deeper decomposition, source checking, alternative generation, and challenge. It never authorizes a write, external action, or autonomous commitment.

## Executive compression

Return the smallest packet that preserves the decision: recommendation, why now, supporting evidence, alternatives rejected, uncertainty, risk/rollback, authority status, and next gate. Expand technical traceability only when the recipient or risk warrants it.
